Student Performance Dashboard 
Excited to share my latest Power BI project — a comprehensive dashboard for analyzing student performance across multiple dimensions.
The dashboard covers 5,000 students across 4 classes with 4 analytical views:
1️. Overview

Pass rate: 94.70% ✅ | Average attendance: 74.92% | Performance breakdown by parental education level
2️. Student Analysis

Average study hours: 3.29 hrs/day | Student distribution by level & gender | Pass/fail comparison across genders (2,553 female | 2,447 male)
3️. Subject Analysis

Math: 76.8% | English: 75.5% | Science: 74.3% | Top 5 students identified across all subjects
4️. Class Analysis

Attendance & absence comparison across 4 classes | Score distribution per class | Consistent overall pass rate: 94.7%
 Tools used: Power BI | DAX | Data Modeling | Data Visualization
This project taught me how to turn raw data into clear, actionable insights for educational institutions — helping educators identify gaps, track progress, and make data-driven decisions.
